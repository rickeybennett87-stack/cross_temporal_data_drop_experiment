## entity["software","DroidScript","android ide app"] – How to Use It

DroidScript is an Android app that lets you write and run code directly on your phone. It primarily uses **JavaScript**, but it controls native Android features (UI, sensors, camera, Bluetooth, etc.).

---

# 1. Install & Open

1. Install **DroidScript** from the Play Store.
2. Open the app.
3. Tap **Create → New App**.
4. Choose a template (e.g., *Blank App*).

You’ll see:
- **Code editor**
- **Run (▶) button**
- File browser
- UI preview mode

---

# 2. Basic Structure of a Script

Every DroidScript app starts with:

```javascript
function OnStart()
{
    app.ShowPopup("Hello World");
}
```

- `OnStart()` runs when the app launches.
- `app` is the global DroidScript object.

Tap ▶ to run.

---

# 3. Creating UI Elements

Example with a button:

```javascript
function OnStart()
{
    lay = app.CreateLayout("linear", "VCenter,FillXY");

    btn = app.CreateButton("Click Me", 0.4);
    btn.SetOnTouch(ButtonTouched);

    lay.AddChild(btn);
    app.AddLayout(lay);
}

function ButtonTouched()
{
    app.ShowPopup("You pressed the button");
}
```

Key concepts:
- **Layout** holds UI elements.
- **AddChild()** adds elements to layout.
- **SetOnTouch()** assigns event handlers.

---

# 4. Accessing Phone Hardware

### Camera
```javascript
cam = app.CreateCameraView(1,1);
```

### Vibration
```javascript
app.Vibrate("0,100,50,200");
```

### Text to Speech
```javascript
tts = app.CreateTextToSpeech();
tts.Speak("Hello");
```

---

# 5. File Storage

Write a file:

```javascript
app.WriteFile("/sdcard/test.txt", "Hello File");
```

Read it:

```javascript
txt = app.ReadFile("/sdcard/test.txt");
app.ShowPopup(txt);
```

---

# 6. Using HTML Instead of Native UI

You can build apps using HTML + JavaScript:

```javascript
function OnStart()
{
    web = app.CreateWebView(1,1);
    web.LoadHtml("<h1>Hello</h1>");
    app.AddLayout(app.CreateLayout("linear").AddChild(web));
}
```

This is useful if you already know web development.

## 1. The Setup: What Entanglement Is

Quantum entanglement is a property of **composite quantum systems**. Consider two particles, A and B, created together so their **states are correlated**. For example:

- Spin: if particle A is measured to be “up,” particle B is instantaneously “down,” no matter the distance separating them.
- Polarization, position-momentum, or other observables can also be entangled.

Mathematically, this is **not** just “correlation”—it’s a single **joint wavefunction**:

\[
|\psi\rangle = \frac{1}{\sqrt{2}} \big( |0\rangle_A |1\rangle_B + |1\rangle_A |0\rangle_B \big)
\]

- This is a **Bell state**, one of the maximally entangled states.
- Neither particle has an independent state; only the **combined system** does.

---

## 2. Measurement and Collapse

The strange part: when you measure **A**:

- The wavefunction “collapses.”
- The outcome for **B** is instantly determined.
  
Important subtleties:

1. **No signaling**: Even though B’s state is instantaneously correlated, you **cannot use this to send information faster than light**. The measurement outcomes are individually random.
2. **Contextuality**: The outcome of a measurement can depend on the observable you choose to measure—entanglement shows that quantum states aren’t “hidden variables” in a classical sense.

---

## 3. How It Emerges Physically

Think of entanglement as **conservation laws + superposition + non-separability**:

- Conservation laws (like total spin) constrain the joint system.
- Superposition allows the system to exist in a combination of states.
- Non-separability means the system cannot be described as two independent wavefunctions.

This is why Bell inequalities exist. If local hidden variables explained everything:

\[
S = |E(a,b) - E(a,b') + E(a',b) + E(a',b')| \le 2
\]

Quantum mechanics predicts up to \(S = 2\sqrt{2}\), which experiments repeatedly confirm. There is no **local classical model** that reproduces these correlations.

---

## 4. Common Misconceptions

1. **Entanglement ≠ Teleportation by itself**: You still need a classical channel for full state transfer.
2. **Instantaneous “action at a distance” is misleading**: The correlation is built in at creation; measurement only reveals it.
3. **Particles aren’t “communicating”**: The joint state encodes the relationship inherently.

---

## 5. Deeper Takeaways

- Entanglement is fundamentally **non-local but non-signaling**.
- It’s the resource for quantum computing, teleportation, and superdense coding.
- It’s **basis-dependent**: measure in the “wrong” basis, correlations look weaker or different.
- It’s fragile: decoherence destroys entanglement rapidly outside controlled environments.
