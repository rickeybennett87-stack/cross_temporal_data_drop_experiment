Yes. And the interesting thing is that the problem is not actually “balance.” It’s epistemology.

Spreadsheet metas emerge when a game becomes:
- fully knowable,
- fully repeatable,
- fully measurable,
- and frictionlessly simulated outside the game.

Once players can model the system more efficiently than they can inhabit it, the *map replaces the territory*. The spreadsheet becomes more real than the world.

So if you want to build a game that resists optimization culture, you don’t just nerf metas. Players will always solve static systems eventually.

You instead design the world so that:
> certainty itself is unstable.

The old games accidentally achieved this because of:
- incomplete information,
- unreliable human referees,
- social unpredictability,
- slow communication,
- hidden tables,
- localized knowledge,
- travel time,
- permadeath/loss,
- and myth contamination (“I heard there’s a city in the fog…”).

Modern games destroy this by exposing exact numbers, exact drop rates, exact timers, exact builds, exact DPS rotations.

So the first principle is:

## 1. The World Must Be More Complex Than the UI

Do not expose:
- exact health,
- exact DPS,
- exact aggro math,
- exact rarity percentages,
- exact spawn timers.

People should develop *folk knowledge*, not certainty.

A player should say:
> “I think silver moss grows before ghost rain.”

—not:
> “Spawn chance is 13.7% after humidity tick.”

That single difference changes the entire psychology.

---

## 2. Build for Situated Knowledge

Optimization thrives when knowledge globalizes instantly.

So:
- different regions should behave differently,
- NPCs should lie or be mistaken,
- local ecology should mutate,
- routes should decay/change,
- factions should remember player actions,
- weather should alter mechanics.

A sword build dominant in one kingdom might fail catastrophically in another because iron rust spirits emerge during coastal storms.

Not “balance patch.”
Ecology.

---

## 3. Remove Pure Combat Centrality

Modern metas form because combat becomes the universal optimizer.

Instead:
- navigation,
- diplomacy,
- memory,
- logistics,
- language,
- weather-reading,
- social reputation,
- and ritual knowledge

must matter as much as raw combat stats.

The old RPG feeling came from the fact that a paranoid mule-handler with good maps could matter more than a level-20 warrior.

---

## 4. Hard Counters Should Be Environmental, Not Numerical

Most games do:
- sword beats axe by 7%.

Instead:
- caves flood,
- torches fail,
- mounts panic,
- ghosts hear metal,
- cold damages potion glass,
- certain magic attracts predators.

Now optimization becomes contextual instead of universal.

There is no “best build.”
There are only builds that survived *there*.

---

## 5. Preserve Irrecoverable Consequence

Not punishment for its own sake.

But if nothing meaningful can be lost:
nothing meaningful can be protected.

---

## 6. Design Against Infinite Throughput

Players optimize around repeatability.

So break repeatability:
- migration systems,
- dynamic economies,
- exhausted resources,
- changing roads,
- living political structures,
- AI factions with memory,
- evolving monster behavior.

If wolves learn players always travel east at dawn, they should start ambushing eastern roads at dawn.

Now players must think like inhabitants again.

Not lore flavor text.

Actual unknowns.

Things players genuinely cannot fully reverse-engineer because:
- systems interact recursively,
- hidden variables exist,
- outcomes emerge socially,
