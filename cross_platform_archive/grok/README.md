# Grok (xAI) Conversation Archive

This directory contains the extracted and indexed Grok conversation export from the raw `prod-grok-backend.json` that was previously buried inside the UUID-named zip at the repository root.

## Contents

- `INDEX.md` — human-readable table of all conversations
- `index.json` — machine-readable index
- `transcripts/` — one Markdown file per conversation, with chronological human/assistant turns, timestamps, and conversation IDs

## Provenance

Extracted from `d1147757-bd15-428e-a265-6f1310816d48.zip` → `ttl/30d/export_data/.../prod-grok-backend.json` (42 MB raw JSON containing 137 conversations).

This makes the Grok-specific history as discoverable and searchable as the Claude, ChatGPT, Gemini, and Copilot sections already present in the archive.
