### 🧠 **JTAG (Joint Test Action Group)**

**What it is**:  
JTAG is a hardware interface standard used for debugging, programming, and testing embedded systems—especially microcontrollers, FPGAs, and SoCs.

**Key Functions**:
- **Debugging**: Halt the processor, inspect memory/registers, step through code.
- **Programming**: Flash firmware directly to chips.
- **Boundary Scan**: Test interconnections on a PCB without physical probes.

**How it works**:
- Uses a serial interface with pins like TDI (Test Data In), TDO (Test Data Out), TCK (Clock), and TMS (Mode Select).
- Communicates with a chip’s internal **Test Access Port (TAP)** to access registers and control logic.

**Use Case**:  
If you’re developing firmware or diagnosing a dead board, JTAG lets you peek inside and manipulate the system at a very low level—even before the OS boots.

---

### 🛠️ **EDL (Emergency Download Mode)**

**What it is**:  
EDL is a special boot mode found in Qualcomm-based Android devices. It allows you to force-flash firmware—even if the device is bricked or the bootloader is corrupted.

**Key Functions**:
- **Unbricking**: Recover devices stuck in bootloops or hard-bricked states.
- **Firmware Flashing**: Load stock ROMs using tools like QFIL or QPST.
- **Bypass Bootloader**: Operates independently of Fastboot or Recovery modes.

**How it works**:
- EDL resides in the **Primary Bootloader (PBL)**, which is rarely corrupted.
- When activated, the device identifies as `Qualcomm HS-USB QDLoader 9008` over USB.
- Communicates using Qualcomm’s **Firehose or Sahara protocols**.

**Activation Methods**:
- Via ADB (`adb reboot edl`) if USB debugging is enabled.
- Via Fastboot (`fastboot oem edl`) if bootloader is accessible.
- **Test Point Shorting**: Physically shorting contacts on the motherboard to trigger EDL.
- Using an **EDL Deep Flash Cable** designed to simulate test point behavior.
