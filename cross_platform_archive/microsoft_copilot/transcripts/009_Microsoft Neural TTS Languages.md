## ⭐ The core answer  
Microsoft Neural TTS **cannot run offline**, but you *can* call it from your HTML app using a simple `fetch()` request to the REST API.

This gives you the **same quality** as Speech Studio’s neural voices.

---

## 🧩 The architecture you need  
Your HTML app will:

1. Send text → your backend (Node/Python/etc.)  
2. Backend calls Azure TTS REST API  
3. Backend returns audio → your HTML app plays it

Why a backend?  
Because **you cannot expose your Azure key in client-side JavaScript** — it would be stolen instantly.

So you need a tiny backend proxy.

---

## 🧪 Minimal working example (HTML + JS + tiny backend)

### **Backend (Node.js example)**  
Put this on your Linux laptop or a cheap cloud host.

```js
import express from "express";
import fetch from "node-fetch";

const app = express();
app.use(express.json());

const key = process.env.AZURE_KEY;
const region = process.env.AZURE_REGION;

app.post("/tts", async (req, res) => {
    const text = req.body.text;

    const ssml = `
        <speak version="1.0" xml:lang="en-US">
            <voice name="en-US-JennyNeural">${text}</voice>
        </speak>
    `;

    const response = await fetch(
        `https://${region}.tts.speech.microsoft.com/cognitiveservices/v1`,
        {
            method: "POST",
            headers: {
                "Ocp-Apim-Subscription-Key": key,
                "Content-Type": "application/ssml+xml",
                "X-Microsoft-OutputFormat": "audio-24khz-48kbitrate-mono-mp3"
            },
            body: ssml
        }
    );

    const audio = await response.arrayBuffer();
    res.set("Content-Type", "audio/mpeg");
    res.send(Buffer.from(audio));
});

app.listen(3000, () => console.log("TTS server running on port 3000"));
```

### **Frontend (HTML + JS)**  
Your HTML app calls your backend:

```html
<button onclick="speak()">Speak</button>
<input id="text" placeholder="Type something">

<audio id="player" controls></audio>

<script>
async function speak() {
    const text = document.getElementById("text").value;

    const response = await fetch("/tts", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ text })
    });

    const blob = await response.blob();
    const url = URL.createObjectURL(blob);

    document.getElementById("player").src = url;
}
</script>
```

This gives you **full neural voice quality** inside your HTML app.
