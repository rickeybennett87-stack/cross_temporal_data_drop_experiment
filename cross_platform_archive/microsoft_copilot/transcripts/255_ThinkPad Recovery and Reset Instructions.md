A **TPM chip**, or **Trusted Platform Module**, is a specialized security component embedded in many modern computers—either as a physical chip on the motherboard or integrated into the CPU itself. It’s like a **hardware vault** for cryptographic secrets.

---

### 🔐 What Does a TPM Do?

- **Stores encryption keys securely**  
  It keeps sensitive data like BitLocker keys, biometric credentials (Windows Hello), and digital certificates locked away from prying software.

- **Verifies system integrity at boot**  
  When your machine powers on, the TPM checks whether the operating system and firmware have been tampered with. If something’s off, it can halt the boot process or trigger recovery.

- **Supports secure authentication**  
  TPM helps enable passwordless login methods, like fingerprint or facial recognition, by storing biometric data securely.

---

### 🧬 TPM Versions and Windows 11

- **TPM 1.2**: Older standard, still functional but less secure.
- **TPM 2.0**: Required for Windows 11. Offers stronger encryption and broader support for modern security features.

You can check if your system has a TPM by opening **Windows Security** → **Device Security** → **Security Processor Details**.
