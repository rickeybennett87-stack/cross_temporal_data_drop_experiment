### 🔎 What Hexadecimal Is
- Hexadecimal (often shortened to *hex*) is a **base‑16 number system**.  
- It uses **16 symbols**:  
  - Digits `0–9` represent values zero through nine.  
  - Letters `A–F` represent values ten through fifteen.  
- Example:  
  - Decimal `10` = Hex `A`  
  - Decimal `15` = Hex `F`  
  - Decimal `16` = Hex `10` (because you’ve “rolled over” into the next place, just like decimal rolls over at 10).  

### 🛠️ Why It’s Useful
- **Computing & Programming:** Hex is compact and maps neatly to binary (base‑2). Each hex digit corresponds to exactly **4 binary bits**.  
  - Example: Binary `1111` = Decimal `15` = Hex `F`.  
- **Color Codes:** In web design, colors are often expressed in hex (e.g., `#FF0000` = pure red).  
- **Memory Addresses:** Hex is used to represent addresses and data in low‑level computing because it’s shorter and easier to read than long binary strings.  

### 🌱 Quick Example
Let’s convert decimal `255` into hex:  
- Divide by 16 → `255 ÷ 16 = 15 remainder 15`.  
- 15 in hex = `F`.  
- So `255` = `FF` in hex.  

That’s why `#FFFFFF` is white in color codes — it’s the maximum value for red, green, and blue channels.
