## On scope conflation.

A new failure mode was identified, named, and added to the protocol today. It is called scope conflation and it has three children.

Scope inflation: a result true in one moment of a chain extracted and applied as a universal rule across all moments. The truth stays the same. The territory it is made to cover grows beyond what the generating moment supports.

Scope collapse: a precise term replaced by a broader one, destroying the definitional boundary that gave the precise term its meaning. The container expands and the precision disappears inside it.

Scope dyslexia: the conflation correctly identified as conflation but the type named wrong, so the correction addresses the wrong boundary and the error persists beneath a label that signals it was resolved.

This failure mode is particularly dangerous because it passes all standard gates. It arrives as a true thing. It fails only on scope. The gate that catches it asks not only is this true but is the scope of its application matched to the moment that generated it.
