# Human Voice Enforcement — Rule 2 Reference: Hedge Phrases
# Companion to: human-voice-enforcement.md

Every phrase below signals writing that approaches its claim rather than stating it.
Delete the phrase. State the thing.

## Category A — Explicit Hedges
- "It is worth noting that"
- "It is important to note that"
- "It is important to consider that"
- "It should be noted that"
- "It should be acknowledged that"
- "It should be mentioned that"
- "It is perhaps worth considering"
- "One might argue that"
- "One might note that"
- "One could consider that"

## Category B — False Modesty
- "Needless to say"
- "It goes without saying that"
- "As one might expect"
- "As we might expect"
- "As one can see"
- "As we can see"

## Category C — Epistemic Cushioning
- "In a sense"
- "In some ways"
- "To some extent"
- "In many respects"
- "For all intents and purposes"
- "By and large"
- "More or less"

## Permitted Hedges (do not flag)
- "Arguably" — when the argument is genuinely contested
- "Perhaps" — when genuine uncertainty exists and matters
- "Possibly" — same
- "I think" / "I believe" — when the first person claim is the actual point

The test: does the hedge carry information, or does it cushion the claim?
If it cushions, delete it.
